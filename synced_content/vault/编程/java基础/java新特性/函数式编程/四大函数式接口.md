# 四大函数式接口

> Java 8 引入的 `java.util.function` 包下的四个核心函数式接口：Consumer、Supplier、Function、Predicate。记忆核心只看**参数**和**返回值**，分别对应"吃进去、凭空造、加工厂、质检员"四种角色。

## 一、什么是函数式接口

**函数式接口**：仅含一个抽象方法的接口，可用 `@FunctionalInterface` 注解标记。例如 `Runnable`、`Comparator`，或自定义接口：

```java
@FunctionalInterface
interface MyFunc {
    void run();
}
```

函数式接口是 **Lambda 表达式与方法引用的"类型载体"**——Lambda 本质上就是函数式接口的简洁实现。

## 二、四大核心接口

四大核心函数式接口分别是：

1. **Consumer\<T\>**（消费型接口）
2. **Supplier\<T\>**（供给型接口）
3. **Function\<T, R\>**（函数型接口）
4. **Predicate\<T\>**（断言型接口）

对比表格：

| 接口名称                 | 中文称呼 | 抽象方法                | 入参    | 返回值         | 核心作用（打个比方）                |
| :------------------- | :--- | :------------------ | :---- | :---------- | :------------------------ |
| **Consumer\<T\>**    | 消费型  | `void accept(T t)`  | 有（1个） | **无**       | **吃进去**，不吐出来（负责处理/打印参数）   |
| **Supplier\<T\>**    | 供给型  | `T get()`           | **无** | 有（1个）       | **凭空造**，只产出（负责生成新对象/随机数）  |
| **Function\<T, R\>** | 函数型  | `R apply(T t)`      | 有（1个） | 有（1个）       | **加工厂**，输入A输出B（负责类型转换/映射） |
| **Predicate\<T\>**   | 断言型  | `boolean test(T t)` | 有（1个） | **boolean** | **质检员**，判断条件是否成立（负责过滤/筛选） |

## 三、代码示例

### 3.1 Consumer（消费）—— 遍历打印

```java
// forEach 方法接收的就是一个 Consumer
list.stream().forEach(item -> System.out.println(item));
```

### 3.2 Supplier（供给）—— 生成数据

```java
// 常用于构造对象或生成随机数
Supplier<LocalDate> supplier = LocalDate::now;
LocalDate today = supplier.get();
```

### 3.3 Function（函数）—— 类型转换

```java
// 将 String 转为 Integer，常用于 map 操作
Function<String, Integer> function = Integer::valueOf;
Integer num = function.apply("123");
```

### 3.4 Predicate（断言）—— 集合过滤

```java
// 筛选出长度大于 3 的元素，常用于 filter 操作
Predicate<String> predicate = s -> s.length() > 3;
list.stream().filter(predicate).collect(Collectors.toList());
```

## 四、如何应用

| 接口            | 典型场景                                     |
| ------------- | ---------------------------------------- |
| **Consumer**  | `forEach`、`peek`、日志输出等"只处理不返回"的场景        |
| **Supplier**  | `orElseGet` 兜底值、对象工厂、延迟求值等"只产出"的场景       |
| **Function**  | `map`、类型转换、字段提取等"一进一出"的转换场景              |
| **Predicate** | `filter`、`removeIf`、`anyMatch` 等"条件判断"场景 |
