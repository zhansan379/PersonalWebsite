# 盲审

> 盲审 = 学位论文的**匿名评审**。隐去作者、导师、学校信息，送第三方/校外专家审核，以保证评分的客观性。

## 一、盲审的范围：并非所有学术写作都要盲审

盲审是**学位论文（毕业论文/毕业设计）**专属的制度，不包括：

| 类型 | 是否盲审 | 说明 |
|---|---|---|
| 毕业论文/毕业设计 | ✅ 是 | 需走盲审/抽检流程 |
| 课程论文/平时作业 | ❌ 否 | 由任课教师直接批改 |
| 开题报告/中期考核 | ❌ 否 | 委员会当面评审 |

## 二、本科 vs 硕士 vs 博士：逐级加码

| 维度 | 本科 | 硕士 | 博士 |
|---|---|---|---|
| **覆盖范围** | 抽检 10%~20% | 多数已推行全员校盲审 | 100% 全员盲审 |
| **评审专家** | 2 位（至少 1 位校外） | 2~3 位校外专家（双盲） | 3~5 位校外/跨校专家 |
| **盲审性质** | 偏"半盲" | 严格双盲 | 双盲 + 教育部抽检 |
| **关注重点** | 格式规范、结构完整、查重 | 工作量、方法科学性、创新点、数据可复现 | **原创性贡献**，一票否决常见 |
| **不通过后果** | 延期答辩，有补救机会 | 延期毕业，严重可能退学 | 当年拿不到学位，需大幅修改重审 |
| **查重门槛** | ≤20%~30% | 去除引用后 ≤10%~15% | 更严，原始数据需可追溯 |

**核心区别**：本科盲审是"及格性把关"，研究生盲审是"学术水平准入"。

## 三、盲审 vs 期刊同行评议

两者都涉及匿名评审，但语境不同：

| | 学位论文盲审 | 期刊审稿 |
|---|---|---|
| 正式名称 | 双盲评阅/校盲审 | 同行评议（Peer Review） |
| 匿名方式 | 隐去作者+导师+学校 | 单盲/双盲/三盲，期刊自定 |
| 是否强制 | 教育部/学校规定，必须走 | 取决于期刊 policy |
| 目的 | 保证学位授予质量 | 保证发表内容的学术可靠性 |

> 投正规学术期刊一定会经过同行评审，但学界说话时会区分"盲审"和"peer review"两个场景。

## 四、盲审与答辩的顺序

盲审是**答辩的前置门槛**，不是并列关系：

```
导师审定定稿 → 查重通过 → [预答辩/院内初审] → ★盲审送审 → 盲审结果 → 答辩 → 学位评定 → 授学位
```

**关键规则**：盲审没过 → 不能参加当批次答辩。这是一个硬规则，没有"先答辩再补盲审"的正常通道。

### 本科的特殊性

本科因抽检制，行政上常将盲审和答辩"并行推进"以节省时间。但逻辑上仍是：盲审结果出来前，被抽中者的答辩处于"待确认"状态。**抽检不合格的话，即便答辩完了，学位申请也会被中止。**

## 五、盲审结果分级

各校用词可能不同，但本质是四级逻辑：

| 盲审结论 | 能否答辩 | 实际含义 |
|---|---|---|
| **同意答辩/通过** | ✅ 直接安排 | 按意见改好即可上台 |
| **修改后直接答辩** | ✅ 需交修改说明 | 小修，导师+学院签字放行 |
| **修改后重新送审** | ❌ 暂不能 | 大修，改完再送第二轮盲审 |
| **不同意答辩/不合格** | ❌ 取消当批次 | 延期半年起步，重新走全流程 |

**一票否决**：3 位专家中 ≥2 位不同意 → 当次申请终止。哪怕只有 1 位不同意，通常意味着 1~3 个月强制冷却期 + 二次送审。

## 六、预答辩 ≠ 正式答辩

三个环节是串联的：

| 环节 | 性质 | 位置 |
|---|---|---|
| **预答辩** | 学院内部模拟（查漏洞） | 盲审**之前** |
| **盲审** | 外部匿名专家终审门槛 | 正式答辩**之前** |
| **正式答辩** | 公开答辩 | 盲审通过**之后** |

完整链路：**预答辩 → 盲审 → 正式答辩**，不能跳级。

## 七、实操建议

1. **本科同学**：别因"只抽检 10%"松懈——教育部抽检是常态，毕业后仍可能被复查，不合格会撤销学位证
2. **研究生同学**：盲审前重点盯三件事——**创新点表述是否清晰、数据能否复现、格式有无致命瑕疵**
3. **无论哪个阶段**：送盲审前必须隐去——致谢中的姓名、页眉校名、在学成果中的具体姓名。格式硬伤最容易吃"不同意答辩"
4. **硕士/博士全员盲审**：把盲审周期（一般 20~45 个工作日）提前算进毕业时间表，不要把盲审提交压到答辩月份才做
