# 戒色每日计划

> 基于「戒为良药」的核心理念：**思想改造是根本，养生运动是保障，避免触发是防线**。

---

## 📋 一日总览

```
06:30  起床 + 冷水洗脸
07:00  早课：戒色文章学习（思想改造）
07:30  晨练（动补）
08:30  早餐 + 食疗
09:00  工作/学习（每45分钟起身活动）
12:00  午餐（清淡为主）
13:00  午休（30分钟，不久卧）
14:00  工作/学习（避免久坐）
17:30  傍晚锻炼（适度运动）
19:00  晚餐（少油少荤）
20:00  晚课：站桩/打坐（补元气）
21:00  放松：阅读/听中医讲座/写戒色日记
22:00  准备入睡（远离电子设备）
22:30  熄灯睡觉（绝不熬夜）
```

---

## 🌅 早上：思想武装 + 激活身体

### 06:30 — 起床

- 立即起床，**不赖床**（赖床容易引发妄想）
- 冷水洗脸，唤醒精神
- 喝一杯温水

### 07:00-07:30 — 早课：思想改造（核心）

> 戒色文章就是一道防火墙。防淫如防火，有了防火墙，就不怕了。

**每日必做**（15-30 分钟）：

- [ ] 阅读一篇戒色文章或戒色笔记
- [ ] 回顾一句核心警句（如"不泄为补，戒为良药"）
- [ ] 默念今日目标："今天我不做欲望的奴隶"

**推荐阅读顺序**：
1. 先读一篇完整的戒色经验文章（10 分钟）
2. 再回顾自己的戒色笔记/摘录（5 分钟）
3. 最后静坐 2 分钟，让正确的思想沉入潜意识

> 原理：通过反复学习、反复灌输来不断强化正气，清除潜意识黄毒。

### 07:30-08:00 — 晨练（动补）

**每天选 1-2 项，不必贪多**：

| 项目 | 时长 | 要点 |
|---|---|---|
| 慢跑 / 快走 | 20 分钟 | 微汗即止，不过度 |
| 八段锦 | 15 分钟 | 重点做"双手攀足固肾腰"固精 |
| 拉伸 | 10 分钟 | 拉开膀胱经，固精关 |

> 双手攀足固肾腰：双腿伸直，弯腰用双手去够脚尖，拉伸大腿后侧。每天压几百下，有效减少遗精。

### 08:30 — 早餐 + 食疗

- 清淡营养，不油腻
- 可参考彭鑫博士食疗方案
- 避免：过油、过荤、过饱

---

## ☀️ 白天：避免触发 + 打破久坐

### 工作/学习纪律

**每 45 分钟必须起身活动 5 分钟**：

- [ ] 站起来走动、拉伸
- [ ] 远眺窗外，让眼睛休息
- [ ] 做几个深蹲或体前屈

> 久坐伤肾。不久坐，是对肾最基本的保护。

### 网络使用守则

> 戒色必须纠正多巴胺失控状态，给自己一个无毒环境。

| ✅ 可以做 | ❌ 绝对不碰 |
|---|---|
| 学习、工作相关内容 | 任何擦边内容（图片、视频、小说） |
| 戒色文章、中医养生内容 | 短视频（算法推荐常带擦边） |
| 佛理、冥想引导 | 深夜独自刷手机 |
| 运动教程 | 无目的浏览（无聊是破戒的导火索） |

**实战技巧**：
- 安装内容过滤插件
- 把戒色文章设为浏览器首页
- 看到擦边内容时，第一反应训练为"不净观/白骨观"，而非"喜欢"

---

## 🌆 傍晚：运动释放 + 饮食控制

### 17:30-18:30 — 傍晚锻炼

> 最大的补就是「不泄为补」，药补不如食补，食补不如动补。

**每天 30-60 分钟，选 1-2 项**：

| 强度 | 项目 | 适用人群 |
|---|---|---|
| 低 | 散步、太极拳、八段锦 | 症状明显、恢复初期 |
| 中 | 慢跑、游泳、骑行、篮球 | 身体状态较好 |
| ⚠️ | 避免力竭式高强度训练 | 过度运动会适得其反 |

### 19:00 — 晚餐

- 少油少荤（减少遗精触发）
- 七分饱，不暴饮暴食
- 不饮酒（酒助邪淫心）

---

## 🌙 晚上：养元气 + 准备入睡

### 20:00-21:00 — 晚课：静功补元气

> 很多神衰患者通过站桩和打坐让自己好起来，贵在坚持。

**每天选 1 项**：

| 项目 | 时长 | 要点 |
|---|---|---|
| 站桩 | 20-30 分钟 | 抱球桩或无极桩，膝盖微曲，脊柱中正 |
| 打坐/冥想 | 20-30 分钟 | 自然呼吸，念头来了不跟随 |
| 深呼吸练习 | 10 分钟 | 腹式呼吸，缓解焦虑 |

### 21:00-22:00 — 自我反思

- [ ] 写戒色日记：记录今天天数、心得、遇到的挑战
- [ ] 听中医/养生讲座或阅读相关书籍
- [ ] 回顾今天是否有不当念头，如何应对的

---

## 🌑 入睡：最关键的红线

### 睡前铁律

> 熬夜 + 纵欲 + 久坐 = 完蛋

| ⚠️ 绝对禁止 | ✅ 推荐替代 |
|---|---|
| 熬夜（最晚 23:00 前） | 22:30 熄灯 |
| 睡前玩手机 | 纸质书 / 无屏幕放松 |
| 睡前打坐（可能引发遗精） | 白天或傍晚打坐 |
| 盖太厚的被子 | 适度轻薄 |
| 睡前大量喝水 | 睡前 1 小时停止饮水 |
| 饱食入睡 | 晚餐与入睡间隔 3 小时以上 |

### 睡前程序（22:00-22:30）

1. 关闭所有电子屏幕
2. 温水泡脚 15 分钟
3. 简单地拉伸或按摩脚底
4. 躺下后默念："明天又是更干净的一天"

## 🆘 应急方案：欲望来袭时

当强烈冲动出现时，**不要与之对抗，而是转移**：

| 方法 | 操作 |
|---|---|
| **立即起身** | 改变环境，离开当前空间 |
| **冷水冲手/脸** | 物理降温打断冲动回路 |
| **体能释放** | 马上做 20 个俯卧撑 / 50 个深蹲 |
| **大声朗读** | 读戒色文章或任何文字，占领大脑 |
| **白骨观训练** | 将冲动对象观想为不净、无常 |
| **打电话** | 给朋友/家人打电话，打破孤独状态 |
| **牢记公式** | 默念"熬夜+纵欲+久坐=完蛋" |

## 🏠 独处防失控预案

> 在家独处时最容易失控。不要靠意志力，要靠环境和替代行为。

### 触发信号 → 立即行动

| 信号出现时 | 立刻做 |
|-----------|--------|
| 在床上躺着想刷手机 | **站起来，立刻离开卧室** |
| 手不自觉想点开短视频 | **锁屏，把手机放在另一个房间** |
| 觉得无聊/空虚 | **出门散步5分钟，或做10个俯卧撑** |
| 晚上睡前 | **手机不进卧室** |

### 环境改造（一劳永逸）

- [ ] **手机不放床头充电** → 放客厅或离床远的地方
- [ ] **卸载所有短视频APP** → 抖音、快手、小红书（如果主要是擦边内容）
- [ ] **电脑浏览器** → 安装屏蔽擦边内容的插件

### 心理调整

❌ "我又没忍住，我要完蛋了"（自我实现的预言）
✅ "这次没防住，但我之前用做家务成功防住了一次。下次我可以……"

### 紧急预案纸条

写一张纸条贴在显眼的地方（比如电脑屏幕边）：

```
⚠️ 当我想"奖励自己"时：

1. 站起来，离开当前位置
2. 喝一杯冷水
3. 做10个俯卧撑或出门走一圈
4. 如果还不行，给我信任的人打个电话

——我不是失控，我只是在调整策略
```

> 重点不是"彻底戒掉"，而是每次察觉后，缩短恢复时间。
