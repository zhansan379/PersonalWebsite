# 轨迹预测

> 基于全部日记中的行为证据，推演不同的可能结局与分岔点。不是算命，是"当前模式 → 必然输出"的逻辑推演。**除非结构性转向，否则最可能的默认结局是"考研放弃、草草将就工作、此后在后悔里回想今天"。**

## 一、惯性滑行下的三种最可能结局

### 结果 A：考研放弃或裸考失败（概率最高，约 60%）
- **证据链**：T-135 天进度基本为零（[[raw/journal/2026-08-11]]）→ 一贯"考前突袭 + 一周没劲"（[[raw/journal/2026-05-26]]）→ 父亲腿骨折、需照顾弟弟等真实干扰（[[raw/journal/2026-07-30]]）。
- 终点大概率是"没去考 / 裸考四科全无把握"，当天写"果然没戏"。
- 这是**成本最低**的结局，因为它不需要改变任何东西。

### 结果 B：考研中途溃退 → 情绪性转向求职 → 将就工作（约 20%）
- 与"投简历受挫 → 转而考研"（[[raw/journal/2026-05-26]]）同构的**反向转换**。
- 结合内向、怕面试、约 10% 回复率（[[日记/求职经验]]），很可能落入县城传统企业或低技术工作。
- 自己最恐惧的画面——"过几年真够呛，结婚得带饥荒，性格不会说话包挨欺负"（[[raw/journal/2026-06-25]]）——有约一半可能被自己亲手选出。

### 结果 C：被家庭责任"拖"着消耗（约 15%）
- 父亲腿骨折 + 照顾弟弟 + 在家，外部责任顺理成章占满时间。
- 这种"忙"没有产出，一年后回头看一样是空的。

## 二、反向证据：指向另一种出口

以下与上述惯性相矛盾，是日记里最有价值的成分：

1. **真实而深刻的自我反思**。[[raw/journal/2026-06-25]] 的 16+1 条规律总结（"午餐后 100% 松懈""空虚感只在午睡过长后出现"）几乎是一种行为实验。**能命名自己模式的人，才有可能打断它。**
2. **Agent / Claude Code 的积累可能是真实差异化优势**。[[raw/journal/2026-08-13]] 对子 agent "汇报丢失 vs 还在跑"的无差别诊断，其编排理解深度不是普通求职者能达到的。2026 年 AI 就业市场里，这比"二本学历"值钱。
3. **被逼时能扛事**。第一反应"烦、不想去"，还是去了并反思"我这样不对"（[[raw/journal/2026-07-30]]）；能洗碗、一天背 160 个单词（[[raw/journal/2026-06-17]]）。**不是废，是"劲只够短跑"。**

## 三、分岔点：恐惧驱动 vs 意义驱动

用拥有者的框架（[[日记/行为模式]]）：当前"系统提示词"是**恐惧驱动**的——四种上下文全是"完蛋了所以必须努力"，而恐惧驱动 = 动力脉冲 = 一周耗尽。

真想改的**不是"更努力"，而是换掉提示词的结构**：

| 惯性提示词 | 替换结构 |
|---|---|
| "距离考研 135 天，我什么都没做，完蛋了" | "今天只学 25 分钟，学完就玩，问心无愧"（6-08 自写信条） |
| "戒色又失败了，我整个人废了" | 不用一场失败定义全天；"靠做家务转移"是已验证的出口（[[raw/journal/2026-06-17]]） |
| "一句招呼语卡我半天，效率真差" | 已进化成"落盘检查而非等通知"（[[raw/journal/2026-08-13]]） |

### 必须回答的一问：到底要不要考研？
- **不要**：越早承认、越早止损，把精力全职放回 AI/Agent 这个有天赋的赛道投简历。否则结局是 B 的"将就"或自己的"后悔"。
- **要**：不靠"劲"，靠把目标缩到不可能失败那么小（25 分钟），**让习惯替代冲劲**。

## 四、待验证假设

- [ ] T+135（考研日）实际结局落在 A / B / C 哪一类
- [ ] 换用"意义驱动 + 极小小目标"后，动力弧线是否超过一周
- [ ] Agent 技能积累能否转化为真实求职/收入结果
