# 晨间提示词模板

> 把大脑当 LLM 来看（[[raw/journal/2026-06-08]]）：环境是显卡、状态是上下文、方法是提示词。当前默认是"恐惧驱动"的提示词，输出的是"动力脉冲 + 一周衰竭"。本模板用于**每天早晨重写那份提示词**，改成"极小小目标 + 意义"驱动，让习惯替代冲劲。

## 一、为什么换

日记自证的两个规律（[[raw/journal/2026-06-25]]、[[日记/行为模式]]）：
- 恐惧驱动（"完蛋了所以必须努力"）→ 初始猛、一周即衰竭。
- "计划的完成后就放松"是自欺欺人 → 一旦开始就停不下来。

所以正确的输入不是"自律、更拼"，而是：
1. **目标小到不可能失败**（对抗动力衰竭）。
2. **给"做完"一个明确的奖励时刻**（替代恐惧的驱动源）。
3. **进食后 / 午睡后设防**（两个 100% 触发松懈的关口）。

## 二、模板结构

```markdown
早安。今天不解决所有问题，只解决这三件。

## 🎯 今天只要做成这三件（每件 ≤ 25 分钟）
- 1. ____________ （做完这一件，上午就通关）
- 2. ____________
- 3. ____________

## ✅ 完成后立刻给奖励
- 我会 ________ （刷 30 分钟 / 玩一局金铲铲 / 看 5 章小说）

## ⏰ 两个设防点
- 午睡前：上闹钟 25 分钟，起来喝口水
- 午饭后：不碰手机，先做那件最机械的一件

## ⚠️ 今天不做的
- ❌ 醒来第一件事刷手机
- ❌ 打开小说 App / 抖音
- ❌ 用 vibe coding 逃避正事

## 🎯 今日一句（意义，不是恐惧）
- 我今天要 ____________________
```

## 三、用例：距离考研 / 求职 X 天

```markdown
今天只学 25 分钟数学，做完就玩，问心无愧。
今天背景：距离考研还有 ___ 天，进度 ________。
我今天要 ______，因为 ______。
```

## 四、填写要点

- **每件压缩到 25 分钟**：不是"复习高数"，是"做第 3 章例题前 5 题"。
- **奖励写具体**："弄完这题玩一局金铲铲"，而不是抽象的自律。
- **设防点固定**：午睡闹钟 + 午饭后先做机械事，这两个时间点最容易全线溃退。
- **意义句跟恐惧句相反**：恐惧句是"完蛋了必须拼"，意义句是"我今天为了____做____"。
