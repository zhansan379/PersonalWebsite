# 行为模式

> 从个人日志中提取的重复性行为模式。识别模式是改变的第一步。

## 一、决策瘫痪

### 1.1 现象

面对需要决策的情境，在多个选项中反复权衡，最终**什么都没做**。

### 1.2 典型案例

实验室需要打扫卫生，面临三个选项：
- A：自己一个人扫了
- B：叫上在场的几个人一起收拾
- C：发通知叫所有人来收拾

在 A/B/C 之间反复犹豫，觉得"好麻烦啊"，最终什么也没干。检查来了也没说什么。

### 1.3 模式特征

- 选项各有优劣，没有明显的最优解
- 内心反复比较但无法下决心
- 时间在犹豫中流逝
- 最终默认选择了"什么都不做"
- 事后有懊悔感（"我感觉我好像袁绍一样"）

### 1.4 可能的应对

- **设定决策时限**：给自己 30 秒做决定，到时间必须选一个
- **降低决策 stakes**：意识到大多数日常决策的后果没那么严重
- **默认执行最简单的选项**：如果无法决定，就做最快能完成的那个
- **事后不反刍**：选了就选了，不纠结"如果选了另一个会不会更好"

## 二、拖延-自责-逃避循环

### 2.1 循环结构

```
正事无聊/困难
    ↓
拖延（找借口：先玩一会）
    ↓
娱乐/消遣（刷抖音、看小说、玩游戏）
    ↓
时间流逝，正事没做
    ↓
自责（"脑子坏掉了"、"自己骗自己"）
    ↓
用更多娱乐逃避自责感
    ↓
正事更紧迫、更不想面对
    ↓
（循环加深）
```

### 2.2 触发条件

- 任务本身枯燥（如整理毕业材料）
- 任务有压力但 deadline 还不够近
- 有更容易获得快感的替代活动（手机、游戏）
- 对自己完成任务的能力缺乏信心

### 2.3 典型表现

- "一点点事老是拖"
- "给自己找借口玩"
- 用搭建知识库、看源码等"看起来有意义的事"逃避真正该做的事
- 正事很无聊 → 所以做别的好玩的事 → 正事更紧迫了 → 更焦虑 → 更需要逃避

### 2.4 可能的应对

- **两分钟法则**：如果一件事两分钟内能开始，立刻开始
- **降低启动门槛**：不想整理全部材料？先打开文件夹
- **物理隔离诱惑源**：把手机放远处/没电（05-26 手机没电反而直接去了实验室）
- **承认自己在逃避**：说出来/写下来"我现在在逃避 XX"，降低自我欺骗的空间

## 三、动力脉冲-快速衰竭

### 3.1 模式描述

受到刺激（焦虑、危机感）→ 产生强烈动力 → 高强度行动 → 约一周后动力消失 → 回到原状。

### 3.2 案例

投简历受挫（海投五六十份，回复率低）→ 恐慌 → 决心考研 → 学了一周 → 没劲了。

背英语单词 → 劲很大 → 一个月没背 → 忘得差不多了。

### 3.3 模式特征

- 动力来源是**负面情绪**（焦虑、恐慌、比较）而非内在兴趣
- 初始强度很高但**不可持续**
- 缺乏中间状态——要么全力冲刺，要么完全放弃
- 缺乏反馈回路——看不到短期成果，动力无法维持

### 3.4 可能的应对

- **设定最小可持续目标**：每天只学 25 分钟，而不是"我要考研"
- **建立习惯而非依赖动力**：固定时间做固定的事，不依赖"感觉有劲"
- **记录小胜利**：每天记录完成了什么，而不是关注还有多少没做
- **接受平台期**：动力起伏是正常的，低动力期不等于失败

## 四、"什么时候干什么事"原则

### 4.1 核心含义

每个阶段有每个阶段的**核心任务**。在该做什么的阶段就专注于什么，不分心、不逃避、不为其他阶段的事过度焦虑。

### 4.2 当前阶段的推论

- 当前最紧迫的：四级考试 → 毕业材料整理 → 优秀论文模板
- 不是当前阶段的：考研（毕业后再考虑）、过度求职（先毕业）
- 分清主次：毕业是前提，其他都是其次

### 4.3 与其它模式的关联

- 这个原则可能是**打破拖延循环**的锚点——问自己"现在这个阶段，我该干什么？"
- 也是**对抗动力衰竭**的方法——不需要长期的宏大目标，只需要知道"这个阶段干什么"

## 五、空虚感触发

### 5.1 关联模式

空虚感（见 [[空虚感分析]]）与拖延循环密切相关：
- 午睡过长 → 空虚感涌现 → 更容易摆烂 → 拖延加深
- 空虚感时更容易选择高刺激活动（刷视频）逃避

### 5.2 交叉触发

空虚感的触发场景（午睡过长）可能成为拖延循环的新入口点。
