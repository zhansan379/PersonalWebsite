# JVM 三大核心功能总结
## 1. 解释和运行

解析 class 字节码指令，实时翻译成底层机器码，交由硬件执行，实现 Java 跨平台特性。
## 2. 内存管理

1. 自动给对象、方法分配运行内存；
2. 内置 GC 垃圾回收，自动释放失效对象占用的内存，无需手动释放。
## 3. 即时编译（JIT）

识别频繁执行的热点代码，做编译优化（指编译后多次调用，会缓存的机制），将字节码转为高效本地机器码，大幅提升程序运行性能。

## 对比编程语言执行效率
1. 静态编译型（AOT 提前编译）
源码 → 编译器 → 机器码（CPU 直接识别），运行时无翻译，速度最快
代表：C、C++
2. 混合编译（JVM 先编译字节码 + JIT 即时编译）
源码 → 编译为中间字节码 → 虚拟机解释执行，热点代码即时编译本地机器码
代表：Java
3. 纯解释型（传统）/ 带 JIT 动态解释
源码 / 中间码运行时实时翻译，无完整提前编译，基础速度慢；现代 JS/Python 带 JIT 大幅提速
代表：Python、JavaScript
